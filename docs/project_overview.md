# Namibia Economic, Energy, Climate Risk & Green Hydrogen Observatory 

## Objectives

Build a reproducible analytic platform for monitoring Namibia's:

- Economic performance 
- Public finances 
- Trade sector
- Energy transition
- Green hydrogen economy
- Climate risks

## Technologies 

- Python
- Pandas
- Git 
- GitHub Actions
- Power BI

## Data Sources

### Automated
 
- World Bank APIs
- NASA POWER API

## Curated

- Namibia Statistics Agency
- Ministry of Finance
- NamPower
- Green Hydrogen Reports

## Outputs

- fact_indicator.parquet
- Power BI Dashboard 
- Quarterly Economic Updates
